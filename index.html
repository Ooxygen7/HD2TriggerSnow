OVERLAY CONTROLS / 悬浮窗控制
SCROLL UP / 向上选择 在悬浮窗的战备列表中向上滚动。(留空为默认配置)
SCROLL DOWN / 向下选择 在悬浮窗的战备列表中向下滚动。(留空为默认配置)
EXECUTE / 执行选定战备 一键执行悬浮窗当前选中的战备指令。(留空为默认配置)
STRATAGEM MENU CONTROL
MENU KEY (DEFAULT CTRL) 你在游戏内用于呼出战备菜单的按键。
TRIGGER MODE (HOLD / TOGGLE) 游戏内的设定：长按呼出，还是按一次切换状态。
HOLD
TOGGLE
MENU OPEN DELAY / 菜单展开等待 (ms) 按下呼出键后，等待多少毫秒再开始输入指令。
PRESS DURATION / 按压时长 (ms) 模拟每次按下方向键的持续时间。
INTERVAL DELAY / 指令间隔 (ms) 松开上一个按键与按下下一个按键之间的间隔时间。
STRATAGEM INPUT KEYS
UP 游戏内设定的“上”指令键。
DOWN 游戏内设定的“下”指令键。
LEFT 游戏内设定的“左”指令键。
RIGHT 游戏内设定的“右”指令键。
